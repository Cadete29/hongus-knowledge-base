# Hongus Knowledge Base

Vault de Obsidian y código del producto Hongus. Reúne visión, producto, arquitectura, seguridad,
diseño, operación y el estado verificable de la implementación en `proyecto/`.

Abre esta carpeta como bóveda y comienza en [[Home]]. Las notas usan enlaces internos de Obsidian y Markdown, sin requerir plugins adicionales.

La documentación distingue hechos confirmados, hipótesis, propuestas y preguntas pendientes.
Consulta [[Brief fundador]] para aportar contexto, [[Estado actual del desarrollo]] para conocer lo
implementado, [[Sistema de tickets en Linear]] para ejecutar el backlog y [[Backlog]] para continuar
la planificación.
